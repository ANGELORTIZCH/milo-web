# Milo · sitio público

Páginas estáticas de Milo (punto de venta para tienditas), publicadas con GitHub Pages:

- `/`: a donde lleva el enlace del correo de confirmación ("¡Listo! Tu correo está confirmado").
- `/nueva-contrasena/`: crear una contraseña nueva desde el enlace de "¿Olvidaste tu contraseña?".
- `/privacidad/`: aviso de privacidad.
- `/terminos/`: términos del servicio.

Este repositorio se genera desde la carpeta `sitio/` del proyecto privado con `scripts/publicar_sitio.sh`, que antes de subir revisa que no haya configuraciones ni claves secretas. No se edita aquí: los cambios hechos directamente se pierden en la siguiente publicación.
